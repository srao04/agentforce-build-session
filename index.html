How to use these files

  1. Open the template. Use the filled example as a reference alongside it.
  2. Fill in all 7 sections. Paste or insert your workflow diagram image into Section 2.
  3. Save as PDF (File → Export → PDF). The diagram and all content goes into one file.
  4. In Claude Code: attach the PDF and paste the build prompt from the last page. Claude derives actions, variables, and topics from your workflow — you don't list them.
